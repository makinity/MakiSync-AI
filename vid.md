> [!IMPORTANT]
> **Why `video_url` MUST stay in the database:**
> The `video_url` column is the essential database property that stores the public file link (e.g. `https://<supabase-id>.supabase.co/storage/v1/object/public/portfolio-media/uploads/my_video.mp4`). Without `video_url`, the frontend HTML5 `<video src={video.video_url} />` player would have no target URL to stream and play. When uploading compressed MP4 files to Supabase Storage, Supabase generates the direct public URL which is saved right into `video_url`.
